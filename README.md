# test-copilot 🚀

This is a test repository for exploring GitHub Copilot features and Python development. It contains sample Python scripts demonstrating basic functionality.

## About This Repository

This repository serves as a testing ground and includes:
- Simple Python scripts for demonstration purposes
- Examples of basic Python functions and input/output operations

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/pallaviraiturkar0/test-copilot.git
   ```

2. Navigate to the project directory:
   ```bash
   cd test-copilot
   ```

3. Ensure you have Python 3.x installed:
   ```bash
   python --version
   # or
   python3 --version
   ```

## Usage

### Running the Hello Script
```bash
python hello.py
# or
python3 hello.py
```

### Running the Sort Descending Script
```bash
python sort_descending.py
# or
python3 sort_descending.py
```

The sort script will prompt you to enter numbers separated by spaces, then display them sorted in descending order.

**Example:**
```
Enter numbers separated by spaces: 5 2 8 1 9
Numbers in descending order: [9, 8, 5, 2, 1]
```

## Repository Contents

- `hello.py` - A simple Hello World script
- `sort_descending.py` - A script that sorts numbers in descending order with user input
