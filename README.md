## 🎮 Game Features

- Bird character with realistic physics (gravity, flapping)
- Scrolling pipe obstacles
- Collision detection with AABB algorithm
- Score tracking and high score persistence
- Game states: Ready → Playing → Game Over
- Restart functionality
- Multiple input methods (keyboard, mouse, touch)
- Responsive design for all devices

## 🛠️ Tech Stack

- React 18+ with Vite
- JavaScript ES6+
- CSS3 for styling
- localStorage for data persistence
- requestAnimationFrame for game loop

## ⏱️ Estimated Development Time

**16-22 hours** for complete implementation following the detailed plan.

## Setup Instructions

1. Clone the repository:
   ```
   git clone https://github.com/pallaviraiturkar0/test-copilot.git
   ```

2. Navigate to the project directory:
   ```
   cd test-copilot
   ```

3. Install the dependencies:
   ```
   npm install
   ```
