# test-copilot 🚀

A simple Python project demonstrating basic Python functionality with two utility scripts.

## Project Overview

This repository contains two Python scripts:

- **hello.py**: A simple script that prints "Hello" to the console
- **sort_descending.py**: A utility script that sorts a list of numbers in descending order

## Requirements

- Python 3.x

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/pallaviraiturkar0/test-copilot.git
   ```

2. Navigate to the project directory:
   ```bash
   cd test-copilot
   ```

3. No additional dependencies are required - the scripts use only Python standard library.

## Usage

### Running hello.py

```bash
python3 hello.py
```

This will output:
```
Hello
```

### Running sort_descending.py

```bash
python3 sort_descending.py
```

You will be prompted to enter numbers separated by spaces. For example:
```
Enter numbers separated by spaces: 5 2 8 1 9
Numbers in descending order: [9, 8, 5, 2, 1]
```
