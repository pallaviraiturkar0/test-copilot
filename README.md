# Test Copilot 🚀

A simple Python project demonstrating basic Python scripting functionality.

## Overview

This repository contains Python scripts for learning and testing purposes:

- **hello.py**: A simple "Hello" message script
- **sort_descending.py**: A utility script that sorts numbers in descending order

## Requirements

- Python 3.x

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/pallaviraiturkar0/test-copilot.git
   ```

2. Navigate to the project directory:
   ```bash
   cd test-copilot
   ```

3. No additional dependencies are required. The scripts use only Python standard library.

## Usage

### Hello Script

Run the hello script:
```bash
python hello.py
```

### Sort Numbers Script

Run the sort script and enter numbers when prompted:
```bash
python sort_descending.py
```

Example:
```
Enter numbers separated by spaces: 5 2 8 1 9 3
Numbers in descending order: [9, 8, 5, 3, 2, 1]
```
