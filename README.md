# test-copilot 🚀

A Python project with utility scripts.

## Scripts

### hello.py
Prints a greeting message to the console.

```bash
python hello.py
```

### sort_descending.py
Accepts a list of numbers from user input and returns them sorted in descending order.

```bash
python sort_descending.py
```

**Example:**
```
Enter numbers separated by spaces: 5 2 8 1 9
Numbers in descending order: [9, 8, 5, 2, 1]
```

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/pallaviraiturkar0/test-copilot.git
   ```

2. Navigate to the project directory:
   ```bash
   cd test-copilot
   ```

3. Ensure Python 3 is installed:
   ```bash
   python --version
   ```
